# PAPERLOOP School Supply Co.

> Learn. Create. Go Further.

PAPERLOOP is a modern school-supply ecommerce storefront for backpacks, notebooks, writing tools, art supplies, organization, calculators, lunch and hydration, and student essentials.

## What is included

- Responsive homepage inspired by the supplied reference architecture
- 18 coordinated catalog products
- Product detail experience
- Search, category filters and sorting
- Browser-persistent cart
- Browser-persistent wishlist
- Back-to-school guide
- Curated collections
- Journal
- Support, FAQ, shipping and returns pages
- Contact/demo form
- Local logo and locally packaged product/category imagery
- No external JavaScript dependencies
- Responsive desktop/tablet/mobile layouts

## Pricing logic

Prices are intentionally matched to the product type and size. Entry-level stationery stays in the single-digit to low-teens range; calculators and backpacks sit higher; bundles and larger durable items carry proportionally higher prices. Sale/reference prices are kept close to the current price so the catalog feels coherent rather than artificially discounted.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- JSON catalog data
- LocalStorage for cart and wishlist

## Status

**Project in development / demo storefront**

## Asset notes

Visual assets are packaged locally so the storefront does not depend on remote image hosts for its product cards. Images are optimized for web presentation and assigned deterministically to their intended product/category sections.
